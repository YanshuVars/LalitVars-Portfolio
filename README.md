# Lalit Kumar Varshney — Portfolio

Professional portfolio website for **Lalit Kumar Varshney**, Senior Manager (Commodity Lead) – Sourcing (CDMM) at Mahindra & Mahindra, Swaraj Division, Mohali.

- **Stack:** Single self-contained `index.html` (HTML + CSS + vanilla JS, no build step)
- **Design:** Light, professional, highly animated — preloader, staggered hero reveal, animated portrait ring, count-up stats, scrolling expertise marquee, animated career timeline, education spotlight, contact section
- **Fonts:** Fraunces + Inter (Google Fonts)

## View

Open `index.html` in any browser, or serve the folder:

```bash
npx serve .
```

## Deploy

This repo is GitHub Pages-ready: **Settings → Pages → Deploy from branch → `main` / root**.
