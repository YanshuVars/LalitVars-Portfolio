# Lalit Kumar Varshney — Portfolio

Professional portfolio website for **Lalit Kumar Varshney**, Senior Manager (Commodity Lead) – Sourcing (CDMM) at Mahindra & Mahindra, Swaraj Division, Mohali.

Two design editions, both self-contained single HTML files (HTML + CSS + vanilla JS, no build step):

- **`index.html`** — v1: light, highly animated, warm ivory + Mahindra red. Staggered hero reveal, animated portrait ring, count-up stats, expertise marquee, animated career timeline, education spotlight.
- **`v2-editorial.html`** — v2: editorial, print-inspired direction. Paper/ink/deep-teal palette, film grain, numbered chapters, arch-framed portrait with rotating badge, interactive career index. No emojis, no glassmorphism.

Fonts: Fraunces + Inter (Google Fonts).

## View

Open either file in any browser, or serve the folder:

```bash
npx serve .
```

## Deploy

GitHub Pages-ready: **Settings → Pages → Deploy from branch → `main` / root** serves `index.html`.
